# 02 · Main — Windows 11

Figma frame: [02 · Main — Windows 11](https://www.figma.com/design/tCFCAuDJvskm2XTh0cOLcX/Modern-terminal?node-id=74-912) (`74:912`)

The main window on Windows 11. Layout and content match [01-main-macos.md](01-main-macos.md); only the window chrome and the modifier key differ.

## Components

- `TitleBar`: app icon on the left; minimise, maximise and close on the right.
- Shortcuts use `Ctrl` (`Ctrl+1`, `Ctrl K`, `Ctrl+D`) in place of `⌘`.
- Every other component is the one described in [01-main-macos.md](01-main-macos.md).

## States

- The states of [01-main-macos.md](01-main-macos.md).
- Window: restored, maximised (no rounded corners, no resize border), snapped.

## Errors and offline

- The rules of [01-main-macos.md](01-main-macos.md).
- A shortcut the system reserves (for example `Win` combinations) is not offered in hints.
