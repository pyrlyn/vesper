# 00 · Reference (original)

Figma frame: [00 · Reference (original)](https://www.figma.com/design/tCFCAuDJvskm2XTh0cOLcX/Modern-terminal?node-id=1-2) (`1:2`)

The original single mockup the other frames were built from: the main window with sessions, workflows, history, command blocks, autocomplete and the Monitor panel, drawn without components. Kept for reference only. Build from [01-main-macos.md](01-main-macos.md) and later frames, never from this one. The mockups call the product Orbit and use a sample project `orbit-api`; read Orbit as Vesper and the sample data as placeholders.

## Components

- The same five regions as frame 01 (title bar, sidebar, main, right panel, status bar), as flat layers.

## States

- One static state: three blocks, the autocomplete open, Monitor on the System tab.

## Errors and offline

- None drawn. Use the error and offline rules of the frame that replaced each region.
